# KPOP Idol SCRUD System

A Flask and MySQL-based web application for managing K-pop groups, idols, albums, and songs.

---

# Introduction

## Background

The popularity of K-pop has grown rapidly worldwide, leading to an increasing amount of information about K-pop groups, idols, albums, and songs. Managing this information manually can become difficult and unorganized. This project was developed to provide a centralized and user-friendly system for storing, managing, and searching K-pop-related data efficiently using a web-based application.

---

## Problem Statement

Many users and fan communities struggle to organize large amounts of K-pop information using manual methods such as spreadsheets or notes. These methods can lead to duplicate records, difficulty in updating information, and inefficient searching. The application aims to solve these problems by providing a searchable and manageable database system with complete SCRUD (Search, Create, Read, Update, Delete) functionalities.

---

## Scope

The project focuses on managing four main categories of K-pop information:

- K-pop Groups
- K-pop Idols
- K-pop Albums
- K-pop Songs

The system includes:
- User login authentication
- Search functionality
- Add, edit, and delete operations
- Responsive and colorful user interface

The project does not include:
- Online user registration
- Real-time API integration
- Music streaming features
- Cloud database hosting

---

## Target Users

The target users of the application include:

- K-pop fans
- Students learning database systems
- Administrators managing K-pop data
- Users who want an organized digital collection of K-pop information

The application benefits users by allowing them to quickly search, organize, and manage K-pop records in a simple and efficient way.

---

# Features

- Search records instantly
- Add new idols, groups, albums, and songs
- Edit existing information
- Delete records
- Responsive colorful UI using Bootstrap
- Login authentication system
